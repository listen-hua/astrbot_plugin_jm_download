## 真实 NapCat 验收清单

当前未接入真实 NapCat 测试账号，以下均为待完成。请使用自己有权访问和分发的内容，勿把文件或敏感截图附在公共 Issue 中。

- [ ] 记录系统、Python、AstrBot 和 NapCat 精确版本与部署方式。
- [ ] 在普通群会话发送有效编号，确认受理、群文件 ZIP、解压后章节和页码一致。
- [ ] 在独立群会话配置下重复验证；多机器人连接时确认文件只到原群。
- [ ] 私聊发送有效编号，确认原用户收到 ZIP。
- [ ] 设置中文密码：无密码和错误密码无法读取，正确密码完整解压。
- [ ] 双容器共享卷：确认 NapCat 读取映射路径，上传返回成功后才清理文件。
- [ ] 使用错误映射或关闭文件权限：确认提示失败，ZIP 保留并可由管理员获取。
- [ ] 超出插件上限保留 ZIP；到期后仅清理自有任务。

完成后可通过 Issue 提交脱敏的版本、部署方式和结果，再更新本表。尚未完成的项目不得标注为已兼容或已实测。
